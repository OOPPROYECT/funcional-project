# Sistema de Gestión de Inventario

Este proyecto consiste en un sistema de gestión de inventario desarrollado en Java utilizando Programación Orientada a Objetos (POO). El sistema permite administrar productos mediante una consola interactiva, aplicando conceptos fundamentales como encapsulamiento, herencia, polimorfismo, interfaces, modularización y manejo de excepciones.

El programa permite:

- Registrar productos.
- Visualizar inventario.
- Modificar stock.
- Eliminar productos.
- Guardar información persistente usando archivos `.txt`.
- Mantener los datos incluso después de cerrar la aplicación.

# Objetivo del Proyecto

Demostrar la aplicación práctica de la Programación Orientada a Objetos mediante un sistema funcional, modular y escalable desarrollado en Java.


# Herramientas de uso

- Java

- Programación Orientada a Objetos
- Colecciones (`HashMap`)
- Manejo de archivos
